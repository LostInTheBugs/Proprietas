PROPRIETAS — macOS VERSION (desktop application)
================================================

What is it?
  Proprietas is a co-ownership (condominium) management application for
  volunteer property managers. This macOS version is self-contained: the
  server and the interface are bundled in the folder — nothing else to
  install, no internet connection required. Your data stays on this
  computer.

Installation
  1. Unzip the « Proprietas-macOS.zip » archive wherever you like
     (e.g. Documents). Keep everything as-is: your data will live next
     to the application.
  2. Double-click « Proprietas.app » — the window opens.

     First launch: macOS may show "macOS cannot verify the developer of
     this application" (normal for an unsigned application). Right-click
     « Proprietas.app » → « Open », then confirm « Open ». Afterwards, a
     double-click is enough.
  3. On first launch, create your manager account (« Premier compte
     (syndic) » tab). The interface is in French.

Your data
  - It lives in the « data » folder, NEXT TO Proprietas.app.
  - Backing up = copying the « data » folder (USB stick, external drive…).
  - Never separate the application from its « data » folder: they go
    together. If the « data » folder does not appear next to the
    application (protected location): Finder → « Go » menu → « Go to
    Folder… » → ~/Library/Application Support/Proprietas

macOS / Gatekeeper
  - The application is not digitally signed: on first launch, macOS may
    show a warning ("macOS cannot verify the developer") — see step 2
    (right-click → Open). Only once.
  - No telemetry: the application does not connect to anything.

Good to know
  - Experimental application, provided as a demonstration: it does not
    constitute legal advice and is not guaranteed to comply with current
    legislation. Consult a professional for legal questions.
  - Updating: download the new version and replace Proprietas.app (keep
    your « data » folder).
  - Source code: https://github.com/LostInTheBugs/Proprietas

Enjoy!
